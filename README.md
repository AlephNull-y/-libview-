# 城市十字路口信号灯仿真（LabVIEW 2014）

一个用 LabVIEW 2014 图形化数据流环境实现的十字路口信号灯仿真系统。以某城市主干路 × 次干路交叉口的实测配时为对象，构建 175 s 周期的信号灯模型，并在实现结构上做了两轮重构：**从 96 格状态查表，到最小项译码，再到有限状态机**。

本项目重点不是"把灯点亮"，而是用数字电路与软件工程的方法审视一张 8×12 的状态矩阵：

- 96 个单元中 80 个取值为 0（83.3%），12 个灯组只呈现 8 种列图样；
- 据此把矩阵解释为「4 个相位 × 2 个阶段（绿/黄）」，按**真值表 → 最小项译码**重构译码层；
- 再把时间基准由"扫描配时表求片号"改为「(片号, 片内秒数)」的 **Moore 型有限状态机**，每拍运算量由 O(8) 降为 O(1)。

两轮重构都以 **175 s 逐秒灯态表**为黄金模型（golden model）做回归验证，分别通过 2100 个与 2625 个状态值的逐值比对。

## 版本演进

| 版本 | 内容 | 关键点 |
|---|---|---|
| V0 | 路灯仿真参考版 | 单灯、单向，用于熟悉 LabVIEW 数据流 |
| V1 | 4 个机动车灯组 | 查表法：8 个时间片 × 4 灯组 |
| V2 | 12 灯组（机动车 + 非机动车 + 行人） | 8×12 状态矩阵，96 格全部人工填写 |
| V3.1 | 译码重构 | 8 个最小项 + 4 个或门 + 8 个非门，取消状态矩阵 |
| V3.2 | 时间基准重构 | 有限状态机 (片号, 片内秒)，O(8) → O(1) |

## 运行环境

- **LabVIEW 2014**（32/64 位均可）。VI 文件为 LabVIEW 2014 格式，更高版本可直接打开；更低版本不支持。
- **Python 3.10+**（可选，仅用于生成数据表与等价性校验）：`Pillow`（画图）、`numpy`（校验脚本，如果用到）。

## 快速开始

1. 打开 `labview/V3-优化/十字路口仿真V3.2_线路优化版.vi`，直接运行——这是最终版本；
2. 想从零理解实现过程，按 `labview/搭建操作手册.md` 从 V1 开始搭；
3. 想核对每一秒的灯态，对照 `labview/V2-功能实现/完整灯态逐秒表.csv`（175 行 × 12 灯组）；
4. 想验证重构前后行为一致，运行 `labview/V3-优化/verify_state_machine.py`。

## 数据说明

所有数值以 CSV 为准，不手填：

| 文件 | 内容 |
|---|---|
| `V1-demo/时间片常量表.csv` | 8 个时间片的起止时刻与 4 灯组取值 |

## 配时方案
