**「确定按钮」放哪、干什么？**

- **放哪**：前面板上随便放，和「停止」按钮放一起就行。它是给**操作的人按**的输入控件，不是灯、不参与显示。
- **干什么**：它是**复位键** —— 按下后把 `t` 归零，信号从「南北直行绿灯」重新开始。名字里的「确定」只是 LabVIEW 自带按钮的外观，跟「确认 / 运行」没有关系。
- **它是可选的**：本次仿真自动循环，完全不需要复位。**不打算做复位就直接删掉这个控件**，前面板更干净，程序也不受影响。
- **⚠️ 关键**：留着它却**没在程序框图里接任何线**，它就只是个摆设 —— 按下去不会有任何反应，也不会让灯变化。这不是故障，别为它排查。
- **想启用**才按 1.6 最后那段接：在 1.3 第 6 步前插一个 `条件结构`，条件接它，真分支输出 0，假分支接原来的余数。

## 1.2 程序框图：建 6 个常量（零基础逐步版）

> 这一节全程在**程序框图**里做。若你现在看到的是有灯和按钮的那一页（前面板），按 **Ctrl + E** 切过去；菜单是「窗口 → 显示程序框图」。  
> 不用怕，下面从第一个鼠标动作开始教。

### 1.2.1 先放一个数组常量，认识它长什么样

1. 在程序框图**空白处点右键** → 弹出「函数选板」。
2. 点选板右上角的「搜索」→ 输入 `数组常量` → 双击结果 → 把出现的框拖到框图上松手。  
   （不想用搜索就按层级找：**编程 → 数组 → 数组常量**）
3. 拖出来是一个**灰色小框**，长这样：

```
   ┌──────────────────────┐
   │ [0]   ░░░░░░░░░░░   │
   └──────────────────────┘
    ↑索引框      ↑元素框（灰色）
```

**三个部件，先分清**：

| 部件        | 在哪       | 作用                           | 常见误操作             |
| --------- | -------- | ---------------------------- | ----------------- |
| 数组外框      | 整个灰框的边   | 拖它可以改变显示多少格子                 | —                 |
| 索引框 `[0]` | 左边的小方框   | 只表示「现在显示的是第几个元素」，**从 0 开始数** | ❌ 别在这里填灯色或秒数      |
| 元素框       | 右边那块灰色区域 | 真正放数据的地方                     | ❌ 刚拖出来是灰的、点不动，属正常 |

> **为什么点不动？** 刚拖出来的数组还不知道自己要装「数字」还是「文字」，所以元素框是空的灰框。必须先塞一个常量进去，它才有类型。

### 1.2.2 四个基本动作（后面 6 个常量全靠这四步）

**动作 A — 给数组定类型**

1. 再放一个 `数值常量`：右键 → 搜索 `数值常量` → 拖到框图**空白处**（先别放进数组）。
2. 鼠标按住这个 `数值常量`，**拖进数组常量的灰色元素框里**，到框内松手。
3. 元素框立刻变成能输入的 `0`。现在它是「数值数组」了。

**动作 B — 改成 I32（32 位整数）**

1. 右键**数组里那个数值元素**（也可以右键数组外框）→ `表示法` → `I32`。
2. 为什么改：要填的都是整数秒数（0、46、175…），统一成 I32，后面连线不会冒出小圆点（强制转换）。
3. 汉化版里 `I32` 也可能写成「长整型」，认那个蓝色整数图标即可。

**动作 C — 拉出格子（显示更多元素）**

1. 鼠标移到数组外框的**右边缘**，光标变成左右双向箭头。
2. **按住左键往右拖**，会看到元素框一格一格多出来。
3. 拖到能看见 **8 个格子**就停（`START`、`END`、`NAME` 都是 8 个）。
4. 新格子里面是**灰色的 0** —— 意思是「还没初始化」，**不是**「值等于 0」。

> ⚠️ 一维数组是**往右**拖（元素横着排），不是往下拖。往下拖是二维加行，见 1.2.5。

**动作 D — 往格子里填数**

1. 用鼠标**单击**某个灰色 `0`（光标变成文字输入状态）。
2. 直接键入数字，按 **回车**，或点一下框图空白处确认。
3. 数字由**灰变黑**，才算这个格子填好了。
4. 从左到右，一格一格填完。

### 1.2.3 六个常量分别是什么

| 名字      | 形状                   | 内容                                   |
| ------- | -------------------- | ------------------------------------ |
| `START` | 一维数值数组，8 格           | `0, 46, 50, 76, 80, 140, 145, 170`   |
| `END`   | 一维数值数组，8 格           | `46, 50, 76, 80, 140, 145, 170, 175` |
| `COLOR` | **二维数值数组，8 行 × 4 列** | 见 1.2.5                              |
| `NAME`  | 一维**字符串**数组，8 格      | 见 1.2.4 第 ④ 步                        |
| `CYCLE` | **单个**数值常量（不是数组）     | `175`                                |
| `N`     | **单个**数值常量（不是数组）     | `8`                                  |

> `CYCLE` 和 `N` 不用数组外框，就是一个孤零零的数字常量。

### 1.2.4 逐个做（照顺序，别跳）

**① 先做最简单的两个：`CYCLE` 和 `N`**

1. 右键 → 搜索 `数值常量` → 拖到框图空白处。
2. 右键它 → `表示法` → `I32`。
3. 单击它，输入 `175`，回车。这就是 `CYCLE`。
4. 同样再做一遍，输入 `8`。这就是 `N`。
5. 怕认错：双击常量旁边的空白处，打一行字 `CYCLE` / `N` 当便签（自由标签，不参与程序）。

**② `START`：一维 8 格数值数组**

1. 按 **动作 A**：放一个 `数值常量` 进 `数组常量` 的元素框。
2. 按 **动作 B**：右键数组里的数值元素 → `表示法` → `I32`。
3. 按 **动作 C**：抓外框**右边缘往右拖**，拖出 8 个格子。
4. 按 **动作 D**：从左到右依次填

   `0` → `46` → `50` → `76` → `80` → `140` → `145` → `170`
5. 填完扫一眼：第 1 格 `0`，第 8 格 `170`，**没有 175**。

**③ `END`：同样的一维 8 格**

1. 重复 ② 的 A→B→C（也可按住 `Ctrl` 拖 `START` 复制一个，再把数字改掉）。
2. 从左到右填

   `46` → `50` → `76` → `80` → `140` → `145` → `170` → `175`

**④ `NAME`：一维 8 格字符串数组**

唯一区别在动作 A —— 这次塞进去的是 `字符串常量`，不是数值常量。

1. 放一个 `数组常量`。
2. 右键 → 搜索 `字符串常量`（层级：**编程 → 字符串 → 字符串常量**）→ 拖进数组的元素框。
3. **不用改表示法**（文字没有 I32）。
4. 抓外框右边缘往右拖出 8 格。
5. 逐格单击，输入这 8 个名字（顺序不能错）：

|  格 | 填什么      |
| -: | -------- |
|  0 | `南北直行绿灯` |
|  1 | `南北直行黄灯` |
|  2 | `南北左转绿灯` |
|  3 | `南北左转黄灯` |
|  4 | `东西直行绿灯` |
|  5 | `东西直行黄灯` |
|  6 | `东西左转绿灯` |
|  7 | `东西左转黄灯` |

1. 中文打不进去时：先**单击格子**让它进入输入状态，再切中文输入法；也可在别处打好字复制粘贴进去。

### 1.2.5 `COLOR`：二维 8 行 × 4 列（唯一麻烦的一个）

**先做一维，再加维度**：

1. 按 ② 的动作 A + B，先做出一个一维数值数组（已放数值常量、已改 I32）。
2. **加维度**：右键数组**左边的索引框 `[0]`** → `添加维度`。  
   左边变成上下两个小框：**上面是行索引，下面是列索引**，都从 0 开始。  
   （另一招：直接往下拖索引框，拖到出现两个框。）
3. 鼠标移到数组外框**右下角**，光标变成斜向双向箭头。
4. 按住左键**往右下方拖**：往右拖出 4 列、往下拖出 8 行，直到能看见 **8 行 × 4 列** 的方格。
5. 逐格单击、输入数字，一行一行来（列顺序固定：`NS_TH, NS_LT, EW_TH, EW_LT`）：

|  行 | 4 个数字     | 对应时间片         |
| -: | --------- | ------------- |
|  0 | `1 0 0 0` | 0—46 南北直行绿    |
|  1 | `2 0 0 0` | 46—50 南北直行黄   |
|  2 | `0 1 0 0` | 50—76 南北左转绿   |
|  3 | `0 2 0 0` | 76—80 南北左转黄   |
|  4 | `0 0 1 0` | 80—140 东西直行绿  |
|  5 | `0 0 2 0` | 140—145 东西直行黄 |
|  6 | `0 0 0 1` | 145—170 东西左转绿 |
|  7 | `0 0 0 2` | 170—175 东西左转黄 |

> 二维的索引框**只控制显示位置**，别把灯色数字填进去。误填了按 **Ctrl + Z** 撤销。

### 1.2.7 卡住了对照这张表

| 现象                          | 原因                  | 怎么办                                    |
| --------------------------- | ------------------- | -------------------------------------- |
| 元素框是灰的、点不动                  | 还没往数组里放常量           | 做动作 A：塞一个 `数值常量` 进去                    |
| 拖不出更多格子                     | 抓错地方                | 一维抓**右边缘往右拖**；二维抓**右下角往右下拖**           |
| 格子里的 0 是灰的                  | 未初始化                | 单击格子 → 键入数字 → 回车，变黑才算数                 |
| 数字填进小方框后数组乱了                | 填到了索引框里             | 索引框只管显示位置；`Ctrl + Z` 撤销，改填右边大格子        |
| 二维数组只有一行                    | 没加维度                | 右键索引框 → `添加维度`                         |
| 中文打不进 `NAME`                | 没进入输入状态             | 先单击格子，再切输入法                            |
| 运行箭头是断的                     | 有端子没连 / 类型不符        | **点一下断箭头**看错误列表，逐条修                    |
| 提示「数据源是 1D 数组，内容为布尔；接收端是布尔」 | `等于?` 的输入是数组而不是单个数字 | 改用 4 个 `索引数组` 从 `COLOR` 直接取标量，详见 1.5.5 |

### 1.2.8 做 1.3 之前，先会这 6 个动作

后面几节全是「放节点 + 连线」，先花两分钟练一遍：

1. **看端子**：程序框图上每个控件/函数左右两侧的小方块就是接线端。
2. **连线**：鼠标移到端子上，光标变成**小线轴**，按住左键拖到另一个端子，松手即连上。
3. **删线 / 撤销**：点中连线按 `Delete`；任何误操作按 `Ctrl + Z`。
4. **复制节点**：按住 `Ctrl` 拖节点，或 `Ctrl + C` / `Ctrl + V`。
5. **移位寄存器**：右键 **While / For 循环的边框** → `添加移位寄存器`；左右边框各出现一个小方块 —— **左边 = 上一轮留下的值，右边 = 传给下一轮的值**。
6. **看不懂某个端子**：按 `Ctrl + H` 打开「即时帮助」，鼠标悬停在函数上，会显示每个端子叫什么、要接什么。**这一招最省事，务必会用**。

再记住两个位置：

- **条件端子**：While 循环**右下角**的小方块，1.3 要接 `stop`。
- **计数端子 N / 计数 i**：For 循环**左上角 N**（接循环次数）、**左下角 i**（当前第几次，从 0 开始）。

## 1.3 搭主循环骨架（逐根线版）

> 目标：做一个每秒走一格的循环，`t` 从 0 走到 174，再自动回到 0。  
> 先把 1.2 的 6 个常量摆到框图**左边**，下面所有节点画在它们右边。

### 先看整体布局：谁在哪个框里

**一句话**：**For 循环整个嵌在 While 循环里面**，不是并排。6 个常量和两个循环都不沾边，放在最外层。

| 位置 | 放哪些节点 |
|---|---|
| **两个循环之外** | 6 个常量 `START` `END` `COLOR` `NAME` `CYCLE` `N`；前面板所有控件在框图里的端子（12 个灯、`t_s`、`remain_s`、`cycle_no`、`slice_name`、`step_ms`、`stop`、`reset`） |
| **While 循环里**（每 1 秒跑一轮） | `等待(ms)`；`加`(t+1)；`商与余数`；**整个 For 循环**；4 个 `索引数组`（从 `COLOR` 取 `s0~s3`）；12 个 `等于?`；`索引数组(NAME, i)`；`索引数组(END, i) 减 t`；`t` 的左右移位寄存器；右下条件端子接 `stop` |
| **For 循环里**（每轮跑 8 次） | `索引数组(START, i)` → `start_i`；`大于等于?`；`选择`；`idx` 的左右移位寄存器；循环计数端子 `i`；左上 `N` 端子（接循环外的 `N=8`） |

```
While 循环（每秒 1 轮）
├─ 等待(ms)、加、商与余数 → t 右移位寄存器
├─ For 循环（跑 8 次）      ← 整个嵌在 While 里面
│    └─ 索引数组(START,i) → 大于等于? → 选择 → idx 右移位寄存器
│         └─ 结果 i 穿过边框出来（输出隧道）
├─ 4 个索引数组(COLOR, 行=i, 列=0/1/2/3) → 12 个等于? → 12 个灯
└─ 索引数组(NAME,i) / 索引数组(END,i) − t → 文字与剩余秒数
```

**边框上的东西**（别放错层）：

- **While 边框**：左边 `t` 移位寄存器（从循环外接初值 `0`）、右边 `t` 移位寄存器（接余数）、右下角条件端子（接 `stop`）。
- **For 边框**：左上角 `N`（接循环外的 `N=8`）、左下角 `i`（当前第几次）、左右各一个 `idx` 移位寄存器（左端从循环外接 `0`）。

> ⚠️ **For 循环的输出隧道必须禁用索引**：从 For 循环右移位寄存器把 `i` 连到 While 层时，边框上会形成一个**输出隧道**。For 循环的输出隧道**默认启用自动索引**，会把 8 次循环的值攒成一个**数组** —— 于是 `i` 变成一维数组，后面 `COLOR` 查表、`等于?` 全会出错，甚至又出现「数据源是 1D 数组」的断线。
> **做法**：右键那个隧道 → `禁用索引`（线变细、方块变实心），输出的才是最后一次循环的**单个数字** `i`。
> 这个坑搞不定时，直接删掉 For 循环，改用 1.8 的 `公式节点` 保底方案 —— 没有嵌套、没有隧道、没有自动索引。

**第 1 步 — 画 While 循环**

1. 右键 → 搜索 `While 循环` → 点结果。
2. 鼠标回到框图上，光标变成虚线框；**按住左键拖出一个大矩形**，把要反复执行的东西圈进去（1.2 的 6 个常量留在框外）。
3. 松手后出现带边框的大框：**右下角小方块 = 条件端子**，**左下角 `i` = 已循环次数**。

**第 2 步 — 加移位寄存器**

1. 鼠标移到 While 循环**左/右边框**上，点右键 → `添加移位寄存器`。
2. 左右边框各出现一个小方块：
   - **左边小方块** = 上一轮传进来的值（这就是当前秒数 `t`）
   - **右边小方块** = 这一轮要传给下一轮的值
3. 在**循环外左边**放一个 `数值常量` → 右键 → `表示法` → `I32` → 填 `0` → 连到**左边小方块**。
   > 这个 0 是第 0 秒的初值。**不接它，灯会乱闪**（1.2 的 ① 已教怎么建单个常量）。

**第 3 步 — 接停止按钮**

1. 前面板的 `stop` 按钮，在框图里有一个同名小端子。
2. 把它连到 While 循环**右下角的条件端子**。
3. 含义：按钮按下 → 循环停下。

**第 4 步 — 加 1 秒节拍**

1. 框内右键 → 搜索 `等待(ms)` → 放进循环里。
2. 把 `step_ms`（那个值为 1000 的数值输入控件）连到它的输入端子。
3. 含义：每轮停 1000 毫秒 = 1 秒。**漏了这步 CPU 会占满、时间飞快**。

**第 5 步 — 算 `t + 1`**

1. 框内放 `加`（编程 → 数值 → 加），它有两个输入 `x`、`y`。
2. `x` 接**移位寄存器左方块**引出来的 `t`（鼠标点在左方块上，按住拖到 `x`）。
3. `y` 接一个数值常量 `1`。输出就是 `t + 1`。
   > 左方块可以同时引出多根线，不影响其他连接。

**第 6 步 — 取余，回到 0**

1. 框内放 `商与余数`。它有 4 个端子：输入 `x`、`y`，输出 `商`、`余数`（**悬停并按 Ctrl + H 可看每个端子名字**）。
2. `x` 接第 5 步结果，`y` 接 `CYCLE`(175)。
3. **只把「余数」输出**连到**移位寄存器右边小方块**；「商」空着不接。
4. 含义：`(t+1) ÷ 175` 的余数。t=174 时 175÷175 余 0，自动回到起点。

✔ **检查**：工具栏最左的**运行箭头**应是完整实心箭头。若断，点一下它会列出错误，最常见三条：移位寄存器左端没接 0、条件端子没接 `stop`、某个端子还空着。

## 1.4 求「当前是第几个时间片」i（逐根线版）

> 结果是 0~7，正好是 `COLOR` 的行号。**这一整段画在 While 循环里面。**

**第 1 步 — 画 For 循环**

1. 在 While 框内右键 → 搜索 `For 循环` → 拖出一个矩形。
2. For 循环**左上角 `N`** = 要跑几次；**左下角 `i`** = 当前第几次（从 0 数到 7）。
3. 把 `N`(8) 常量连到 `N` 端子 → 固定跑 8 次。

**第 2 步 — 给它也加移位寄存器**

1. 右键 For 循环边框 → `添加移位寄存器`。
2. **左端（框外）接一个 I32 常量 `0`** —— 这是索引的初值。

**第 3 步 — 循环内放 3 个节点，依次连**

1. `索引数组`：数组端子接 `START`，索引端子接 For 循环的 `i` → 输出 `start_i`（当前片的起点秒数）。
2. `大于等于?`：`x` 接 `t`（While 的移位寄存器左方块），`y` 接 `start_i` → 输出布尔 `ge`。
3. `选择`：把鼠标悬停上去按 `Ctrl + H`，会看到 3 个输入 + 1 个输出：

| 端子        | 接什么              |
| --------- | ---------------- |
| `s`（选择端）  | `ge`             |
| `t`（真值输入） | For 循环的 `i`      |
| `f`（假值输入） | For 循环**左**移位寄存器 |
| 右侧输出      | For 循环**右**移位寄存器 |


**第 4 步 — 取结果**

For 循环**右**移位寄存器引出来的值，就是 `i`（0~7）。把它留给 1.5 和 1.6 用。

> 原理：i 从 0 到 7 依次问「t ≥ 这个片的起点吗」，**最后一个成立的号**就是当前时间片。  
> 举例：t=46 时，起点 0 和 46 都满足、50 不满足，所以最后成立的是 i=1（南北直行黄灯）。

✔ **检查（必做）**：临时放一个数值显示控件，把 `i` 接上去，运行并看 `t_s`：

| t_s | i 应显示 |
| --: | ----: |
|   0 |     0 |
|  46 |     1 |
|  50 |     2 |
|  80 |     4 |
| 174 |     7 |

不对就把 `选择` 的 `t` / `f` 两根线对调。对完删掉临时显示。

### 1.4.1 典型故障：数字在跳，灯一直不变

**症状**：`t_s` 正常变化，但 `slice_name` 一直显示「东西左转黄灯」，灯永远是 `EW_LT_Y` 亮黄 + 另外三组红灯。

**这就是 `i` 恒为 7**（程序永远取 `COLOR` 最后一行 `0 0 0 2`）。按上表把 `i` 接出来，八成看到它一直是 7。有**两处**接线会导致这个结果，两处都要查：

| 位置 | 正确接法 | 接反之后 |
|---|---|---|
| `大于等于?` | `x` 接 `t`，`y` 接 `start_i`（算 `t ≥ 起点`） | 变成算「起点 ≥ t」，末尾几片全成立 → `i` 跑到 7 |
| `选择` | `s` 接 `ge`、**`t`（真值）接 `i`**、**`f`（假值）接左移位寄存器** | 真时保持旧值、假时写入 `i` → `i` 跑到 7 |

**逐处核对**：鼠标悬停在每个端子上按 `Ctrl + H` 看端子名；确认 `选择` 的选择端接布尔 `ge`、真值端接循环计数 `i`、假值端接 For 循环**左**移位寄存器。

**修好后的样子**：`t_s=0` → 南北直行绿灯、`NS_TH_G` 亮；`t_s=46` → 南北直行黄灯、`NS_TH_Y` 亮；`t_s=80` → 东西直行绿灯、`EW_TH_G` 亮。

> 顺带看 `remain_s`：若 `t_s=18` 时它显示 `157`，说明接成了 `175 − t`；正确是 `索引数组(END, i) 减 t`（此时应为 `28`）。见 1.6。

**卡住了？** 删掉这个 For 循环，改用 1.8 的 `公式节点` 保底方案（复制代码即可，不用接这 4 根线）。

## 1.5 取灯色、点亮 12 个灯（逐根线版）

**第 1 步 — 用 4 个 `索引数组` 直接取出 4 个标量**

> ⚠️ 这一节旧版曾推荐「抽取一维数组」，**那是错的**：NI 官方文档写明它的输出是「若干**输出数组**」，不是单个数字。用它接 `等于?` 一定会产生布尔数组断线。正确做法如下。

1. 放 **4 个** `索引数组`，每个的「数组」端子都接 `COLOR`（二维）。
2. 每个节点**往下拖**拉出两个索引端子：**上面是行索引，下面是列索引**。
3. **4 个行索引全部接 `i`**（从 1.4 的结果引一根线，分四路）。
4. **列索引分别接数值常量 `0`、`1`、`2`、`3`**。
5. 这 4 个节点的输出都是**单个数字**（细线），依次是 `s0`、`s1`、`s2`、`s3`。

> 原理：二维数组**行、列索引都接上**时，`索引数组` 输出的是「元素」＝标量；**只接行索引**输出的是「子数组」＝一维数组，那正是断线的来源。  
> 用 `Ctrl + H` 悬停输出线，确认类型写的是数值标量，而不是「1D 数组」。

**第 2 步 — 确认这 4 根是细线**

把鼠标分别悬停在 4 根输出线上按 `Ctrl + H`：都应显示数值（标量）。**若显示「1D 数组」，说明列索引没接上**，回头补第 4 步。

**第 3 步 — 放 12 个 `等于?`**

1. 先放一个 `等于?`：一个输入接 `s0`，另一个输入接数值常量 `0` → 它的输出就是「南北直行**红**灯」。
2. 按住 `Ctrl` 拖这个节点复制，共凑够 **12 个**（或 `Ctrl + C` / `Ctrl + V`）。
3. 按下表，把每个 `等于?` 的**两个输入**和**输出**接好：

| 色值        | 红灯（连 `*_R`） | 绿灯（连 `*_G`） | 黄灯（连 `*_Y`） |
| --------- | ----------- | ----------- | ----------- |
| `s0` 南北直行 | `s0 == 0`   | `s0 == 1`   | `s0 == 2`   |
| `s1` 南北左转 | `s1 == 0`   | `s1 == 1`   | `s1 == 2`   |
| `s2` 东西直行 | `s2 == 0`   | `s2 == 1`   | `s2 == 2`   |
| `s3` 东西左转 | `s3 == 0`   | `s3 == 1`   | `s3 == 2`   |

读法举例：`s0 == 1` 就是「把 s0 和一个常量 1 接进同一个 `等于?`」，这个 `等于?` 的输出连到 `NS_TH_G`（南北直行绿灯）。

**第 4 步 — 连到灯**

1. 每个 `等于?` 的输出端子，连到**前面板对应名字的灯**在框图里的小端子。
2. 找法：切回前面板看灯的标签（例如 `NS_TH_R`），框图里同名的小方块就是它。
3. 连错随时 `Ctrl + Z`；一根布尔线可以连多个灯端子（V2 会用到）。

✔ **检查**：把 `step_ms` 改成 `20` 快速跑 —— 每组**恰好亮一个灯**，且全场只有一个灯组是绿或黄。若一组同时亮两个，多半是 `等于?` 的常量写成了 1/2/4，按 1.2 的编码改回 `0红 1绿 2黄`。

### 1.5.5 最常见的断线：布尔数组连到单个灯

**报错长这样**（即时帮助 / 错误列表里）：

> 断线：`NS_TH_R`（布尔（TRUE或FALSE））  
> 已连接两个不同类型的接线端。  
> 数据源的类型是 **1D 数组，内容为 布尔（TRUE或FALSE）**。  
> 数据接收端的类型是 **布尔（TRUE或FALSE）**。

**原因（一句话）**：`等于?` 的**输入里有一个是数组**，所以它的输出也成了「布尔一维数组」；灯只收一个布尔，于是断线。

**最容易踩的坑（本手册旧版写错，已更正）**：`抽取一维数组`（Decimate 1D Array）**不能用来拆成标量**。NI 官方中文文档原话是「使数组的元素分成若干**输出数组**」—— 它的每个输出端子出来的仍然是**一维数组**。所以「已经接了抽取一维数组还报错」是正常的，接了也白接。

**怎么确认**：鼠标悬停在那根线上按 `Ctrl + H`，看类型写的是「布尔」还是「1D 数组」。**LabVIEW 里数组线比标量线粗**，一眼也能分辨。

**正确修复（4 步，12 个断线一起消失）**：

1. **删掉** `抽取一维数组` 以及它到 12 个 `等于?` 的连线（留着没用）。
2. 放 **4 个 `索引数组`**，每个的「数组」端子都接 `COLOR`（二维）。
3. 每个节点拉出两个索引端子：**行索引全部接 `i`**，**列索引分别接常量 `0`、`1`、`2`、`3`**。
4. 这 4 个输出都是**标量**，分别接进 12 个 `等于?`（按第 3 步的表）。每个 `等于?` 的输出就变回单个布尔，可直接连灯。

> 原理：二维数组**行、列索引都接上** → `索引数组` 输出「元素」（标量）；只接行索引 → 输出「子数组」（一维数组），后者正是断线来源。
>
> ⚠️ 也别用「创建数组」把 12 个 `等于?` 的输出合并后再连灯，那会把错误放大到 12 处。

**修完验证**：点一下断箭头打开错误列表，应一条不剩；再把 `step_ms` 设成 `20` 快跑，每组恰好亮一个灯。

## 1.6 接显示

| 显示             | 接法                                                             |
| -------------- | -------------------------------------------------------------- |
| `slice_name`   | `索引数组(NAME, i)`                                                |
| `remain_s`     | `索引数组(END, i)` 减 `t`（`减`）                                      |
| `t_s`          | 直接接 `t`                                                        |
| `cycle_no`（可选） | **While 自带的 `i`** → 新放一个 `商与余数`（÷ `CYCLE`=175）→ **商** → `加`(1) → `cycle_no`，详见 1.6.1 |

`reset`（可选）：在 1.3 第 6 步前插一个 `条件结构`，条件接 `reset`；真分支输出 0，假分支接原来的余数。

> ⚠️ `remain_s` 是「**本时间片**还剩几秒」，不是「本周期还剩几秒」。必须用 `索引数组(END, i) 减 t`。
> 若接成 `CYCLE(175) 减 t`，`t_s=18` 时会显示 `157`（正确应为 `46−18=28`）。这个错不影响灯，但数字会看不懂。
> `cycle_no` 显示 0 表示这个可选功能还没接，不影响仿真；按上表接好后第一周期应显示 1。

### 2.1.1 格子填错会怎样，以及怎么查

`COLOR` 是 96 个格子，**任意一格写错，只会坏那一个灯**，而且现象很迷惑人：**红灯常亮、绿灯怎么都不亮**。原因很简单 —— 查表结果既不是 `0` 也不是 `1` 时，红灯的 `s==0` 和绿灯的 `s==1` **同时为假**，那组灯就不会按预期变色。

**三个查法，任选**：

1. **跑脚本（最省事，不用开 LabVIEW）**：在 `V2-功能实现` 目录下

   ```
   python check_color_table.py
   ```

   它直接读 `.vi` 文件里那张 8×12 表，逐格和基准比，会打印整张表并列出「第几行 × 第几列，现在是几，应为几」。全对时输出 `[通过]`。
2. **手数格子**：二维数组常量里，**行 = 片号**（第 1 行是片 1），**列 = 灯组**（第 5 列才是 `BK_NS_TH`）。单击格子看它是不是只有 `0/1/2` 三种值之一 —— 出现别的数一定是错的。

> ⚠️ 另一种常见错法：**相邻两行抄串**。表现是「某个灯提前一个片亮、该亮的时候反而灭」。修法是把多出来的 `1` 从上一行删掉、再补到下一行对应格子 —— 删和补要对齐，只删不补会变成"那只灯永远不亮"。改完跑一次上面第 1 条。

## 常见错（按现象查）

| 现象          | 原因               | 修                                           |
| ----------- | ---------------- | ------------------------------------------- |
| 灯乱闪、全灭      | 移位寄存器没接 0        | 左端补 I32 常量 `0`                              |
| CPU 占满、时间飞快 | 漏了 `等待(ms)`      | 补上，接 `step_ms`                              |
| t=46 还是绿灯   | 比较写成了 `<=`       | 一律用 `>=` 配合 `[start, end)`                  |
| 一组同时亮两个灯    | `等于?` 常量写成 1/2/4 | 严格 `0=红 1=绿 2=黄`                            |
| 出现 `t=175`  | 取余写成 `t mod 175` | 改成 `(t+1) mod 175`                          |
| 第 8 片被拆两段   | `START` 里多了 175  | 只留 0…170 共 8 个                              |
| 停止要点两次      | 按钮机械动作           | 右键 → `机械动作` → 选「释放时锁存」(Latch When Released) |
| 2014 打不开 VI | 被新版 LabVIEW 另存过  | **只用 LV2014 打开和保存**                         |
| 某只绿灯永远不亮、红灯常亮 | 该灯组在 `COLOR` 里的格子不是 `0/1/2` | 按 2.1 的表核对该列 8 格，或跑 `check_color_table.py` |
| 灯提前一个片亮、该亮时反而灭 | 相邻两行数字抄串（上一行多个 `1`、下一行少个 `1`） | 把多余的 `1` 删掉、补到正确那一行，见 2.1.1 |

## 要改配时时

只改 `V1-demo/gen_timing_table.py`（V1）或 `V2-功能实现/gen_timing_table_v2.py`（V2）顶部的 `PHASES`；改完在各自目录运行 `python gen_timing_table.py` / `python gen_timing_table_v2.py`，再照新 CSV 更新 6 个常量。程序框图结构不用动。

> ⚠️ 重跑前**先关掉 Excel 里打开的 CSV**，否则文件被锁会报 `PermissionError`（数据不会被破坏，关闭后重跑即可）。

> 当前基准方案：周期 **175 s**，8 个时间片，绿灯合计 157 s、黄灯 18 s，全红 **0 s**。  
> 若现场确认每相位后有全红 R 秒，周期改为 `175 + 4R`，脚本会自动刷新全部表。
