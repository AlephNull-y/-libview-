## 0. 这份图纸要解决什么

本仿真**只模拟信号灯指示逻辑**，不接车流、不计算延误与排队。输入是现场实测整理的固定配时表，输出是四个机动车灯组在每一秒的红/黄/绿状态，按 175 s 周期无限循环。

本次建模范围（已与需求确认）：

- ✅ 4 个机动车主灯组：`NS_TH` 南北直行、`NS_LT` 南北左转、`EW_TH` 东西直行、`EW_LT` 东西左转
- ❌ 不建非机动车灯、不建 8 个人行灯 —— 交接文档第 5 节明确列为「待现场确认」，不得编造
- ❌ 不建右转灯组（暂按右转不受灯控）
- ❌ 全红按 **0 s**，不插入全红时间片
- ❌ 不含公交优先、感应控制、分时段配时、云智慧交通管控调整

配套文件（同目录）：

| 文件 | 用途 |
|---|---|
| `gen_timing_table.py` | 配时的**唯一定义处**。改秒数后重跑，自动刷新下面两张表并做一致性校验 |
| `时间片常量表.csv` | 8 行，直接照抄成 LabVIEW 数组常量 |
| `逐秒核对表.csv` | 175 行（t=0…174），验收时逐秒比对，同时给中文灯色和 0/1/2 数值 |
| `十字路口仿真.vi` | 你已建好的空 VI，按本图纸往里填 |

## 1. 设计输入（锁死，不得在 VI 里另改成别的数）

### 1.1 相位与时长

| 相位 | 放行灯组 | 绿+黄总时长 | 黄灯 | 纯绿灯 | 绿起止 | 黄起止 |
|---|---|---:|---:|---:|---|---|
| 1 | `NS_TH` 南北直行 | 50 s | 4 s | 46 s | 0—46 | 46—50 |
| 2 | `NS_LT` 南北左转 | 30 s | 4 s | 26 s | 50—76 | 76—80 |
| 3 | `EW_TH` 东西直行 | 65 s | 5 s | 60 s | 80—140 | 140—145 |
| 4 | `EW_LT` 东西左转 | 30 s | 5 s | 25 s | 145—170 | 170—175 |

**周期 T = 175 s**；绿灯合计 157 s，黄灯合计 18 s，校验 157 + 18 = 175。
任一机动车相位放行时，其余三个机动车灯组**恒为红灯**。

### 1.2 灯态编码

程序框图里用一个 I32 数值表示某灯组当前颜色：

| 数值 | 含义 |
|---:|---|
| `0` | 红 |
| `1` | 绿 |
| `2` | 黄 |

三个灯必须互斥：任一时刻每组恰好一个布尔为 TRUE。

### 1.3 8 个时间片常量表（照抄）

列顺序固定为 `NS_TH, NS_LT, EW_TH, EW_LT`。时间片一律**左闭右开** `[start, end)`：例如 t=46 属于第 2 片（黄灯），不属于第 1 片。

| 片号(1-8) | 索引 i(0-7) | start | end | 名称 | NS_TH | NS_LT | EW_TH | EW_LT |
|---:|---:|---:|---:|---|---:|---:|---:|---:|
| 1 | 0 | 0 | 46 | 南北直行绿灯 | 1 | 0 | 0 | 0 |
| 2 | 1 | 46 | 50 | 南北直行黄灯 | 2 | 0 | 0 | 0 |
| 3 | 2 | 50 | 76 | 南北左转绿灯 | 0 | 1 | 0 | 0 |
| 4 | 3 | 76 | 80 | 南北左转黄灯 | 0 | 2 | 0 | 0 |
| 5 | 4 | 80 | 140 | 东西直行绿灯 | 0 | 0 | 1 | 0 |
| 6 | 5 | 140 | 145 | 东西直行黄灯 | 0 | 0 | 2 | 0 |
| 7 | 6 | 145 | 170 | 东西左转绿灯 | 0 | 0 | 0 | 1 |
| 8 | 7 | 170 | 175 | 东西左转黄灯 | 0 | 0 | 0 | 2 |

由此得到四个一维 I32 数组常量：

```
边界数组 START = [0, 46, 50, 76, 80, 140, 145, 170]      (8 元素)
结束数组 END   = [46, 50, 76, 80, 140, 145, 170, 175]    (8 元素)
灯色表 COLOR   = 8 行 × 4 列二维数组，数值见上表右侧 4 列
时间片名 NAME  = ["南北直行绿灯","南北直行黄灯","南北左转绿灯","南北左转黄灯",
                  "东西直行绿灯","东西直行黄灯","东西左转绿灯","东西左转黄灯"]
周期 CYCLE     = 175
```

> ⚠️ `START` **不要**加 175。t 的取值范围是 0…174，t=175 会立即归零，不存在第 175 秒。

## 2. 前面板施工图

### 2.1 布局示意

```
┌──────────────────────────────────────────────────────────────┐
│  主干路 × 次干路 · 固定配时基准仿真（周期 175 s）           │
│  周期内秒 t = [  0 ] s     第 [ 1 ] 周期                     │
│  当前时间片：[ 南北直行绿灯 ]   本片剩余：[ 46 ] s            │
├───────────────────────────────┬──────────────────────────────┤
│  南北方向（主干路）          │  东西方向（次干路）           │
│                               │                              │
│  直行   ●红  ●黄  ●绿         │  直行  ●红  ●黄  ●绿          │
│  左转   ●红  ●黄  ●绿         │  左转  ●红  ●黄  ●绿          │
├───────────────────────────────┴──────────────────────────────┤
│  [ 停止 ]   [ 复位 ]   步长(ms) [ 1000 ]                     │
└──────────────────────────────────────────────────────────────┘
```

共 **12 个圆形指示灯**（4 灯组 × 红/黄/绿 3 色）。想更像真实路口，可用 `Controls → Modern → Decorations` 里的矩形/直线画道路与停止线，把灯摆到四个进口道位置；这属于美化，不影响逻辑，建议逻辑跑通后再加。

### 2.2 控件清单

| 控件 | 选板路径（LV2014） | 类型 | 命名 | 初值/说明 |
|---|---|---|---|---|
| 12 个指示灯 | `Modern → Boolean → Round LED` | Boolean Indicator | 见下表 | 每组红/黄/绿各一个 |
| 周期内秒 | `Modern → Numeric → Numeric Indicator` | I32 | `t_s` | 显示 0…174 |
| 周期号 | `Modern → Numeric → Numeric Indicator` | I32 | `cycle_no` | 从 1 开始 |
| 时间片名 | `Modern → String & Path → String Indicator` | String | `slice_name` | — |
| 本片剩余 | `Modern → Numeric → Numeric Indicator` | I32 | `remain_s` | `END[i] - t` |
| 停止 | `Modern → Boolean → Stop Button` | Boolean Control | `stop` | 接 While 条件端子 |
| 复位 | `Modern → Boolean → OK Button` | Boolean Control | `reset` | 可选功能 |
| 步长 | `Modern → Numeric → Numeric Control` | I32 | `step_ms` | **默认 1000**，验收时可改小 |

12 个 LED 的命名（`R`=红、`Y`=黄、`G`=绿）：

| 灯组 | 红 | 黄 | 绿 |
|---|---|---|---|
| 南北直行 `NS_TH` | `NS_TH_R` | `NS_TH_Y` | `NS_TH_G` |
| 南北左转 `NS_LT` | `NS_LT_R` | `NS_LT_Y` | `NS_LT_G` |
| 东西直行 `EW_TH` | `EW_TH_R` | `EW_TH_Y` | `EW_TH_G` |
| 东西左转 `EW_LT` | `EW_LT_R` | `EW_LT_Y` | `EW_LT_G` |

### 2.3 LED 颜色设置（每个灯都要设）

`Round LED` 默认「亮=绿、灭=暗绿」，直接用会看不出红黄绿，必须逐个改：

1. 右键 LED → `Properties` → `Appearance` 选项卡 → `Colors` 区域。
2. 分别点 `On` / `Off` 色块，选自定义颜色，按下表设置：

| 灯 | On 颜色 | Off 颜色 |
|---|---|---|
| 红灯 `*_R` | 亮红 `#FF2020` | 深灰 `#404040` |
| 黄灯 `*_Y` | 亮黄 `#FFD400` | 深灰 `#404040` |
| 绿灯 `*_G` | 亮绿 `#20D020` | 深灰 `#404040` |

3. 建议同时把 `Label` 改成「红/黄/绿」，并在每组上方放一个 `Free Label` 写「南北直行」等，避免连错线。

> 用 12 个独立 LED 而不是 1 个三色控件，是因为 LV2014 的布尔指示灯只有 On/Off 两态；三色必须用三个布尔量表达，这也正好对应真实灯头的三个灯。

## 3. 程序框图施工图（主方案：纯 G 查表状态机）

### 3.1 整体结构

```
                        ┌──────── While 循环 ────────┐
                        │                            │
  [0] ──→ 移位寄存器 t ─┤                            │
                        │  ┌─ 求时间片索引 i ─┐      │
                        │  │ For N=8          │      │
                        │  │  start=START[i]  │      │
                        │  │  t >= start ?    │      │
                        │  │  Select → idx    │      │
                        │  └────────┬─────────┘      │
                        │           │ i (0..7)       │
                        │  ┌────────┼─────────────┐  │
                        │  │        │             │  │
                        │  │  Index Array(COLOR,i)│  │
                        │  │        ↓ [s0..s3]   │  │
                        │  │  Decimate 1D Array  │  │
                        │  │        ↓ s0 s1 s2 s3│  │
                        │  │  Equal?(s,0/1/2)×12  │  │
                        │  │        ↓ 12 布尔    │  │
                        │  │  → 12 个 LED        │  │
                        │  └─────────────────────┘  │
                        │  Index Array(NAME,i) → 时间片名        │
                        │  Index Array(END,i) − t  → 本片剩余     │
                        │  t → t_s                              │
                        │  Wait (ms) = step_ms                  │
                        │  (t+1) mod 175 → 右移位寄存器 t        │
  [stop] ──────────────┤→ 循环条件端子                          │
                        └────────────────────────────────────┘
```

### 3.2 循环外：建 6 个常量

`Programming → Array → Array Constant`，拖到框图、拉伸维度后填入 1.3 节的数值：

| 常量 | 维度 | 数据类型 | 内容 |
|---|---|---|---|
| `START` | 1D / 8 元素 | I32 | `[0,46,50,76,80,140,145,170]` |
| `END` | 1D / 8 元素 | I32 | `[46,50,76,80,140,145,170,175]` |
| `COLOR` | 2D / 8 行 × 4 列 | I32 | 见 1.3 表右侧 4 列 |
| `NAME` | 1D / 8 元素 | String | 见 1.3 节 |
| `CYCLE` | 标量 | I32 | `175` |
| `N` | 标量 | I32 | `8` |

> 填二维数组常量时，先把索引框拉成 2 维，再纵向拉出 8 行、横向拉出 4 列，逐格填。填完对着 `时间片常量表.csv` 复核一遍。

### 3.3 逐步连线

**Step 1 — While 循环**：`Programming → Structures → While Loop` 拖一个大方框，把常量留在框外、逻辑放框内。停止按钮 `stop` 连到右下角条件端子（默认 `Stop if True`，不用改）。

**Step 2 — 移位寄存器 t**：在 While 左右边框右键 → `Add Shift Register`。左侧（循环外）接 I32 常量 `0` **初始化**。右侧接 Step 9 的 `t_next`。左端子引出线即当前 `t`。

**Step 3 — 求时间片索引 i**（这段是状态机的核心）：

- `Programming → Structures → For Loop`，把 `N=8` 连到计数端子 `N`。
- 在 For 循环边框右键 → `Add Shift Register`，左侧循环外接 I32 常量 `0`（索引初值）。
- 循环内：
  - `Index Array`（`Programming → Array`）：输入 `START` 和循环计数端子 `i`，输出 `start_i`。
  - `Greater or Equal?`（`Programming → Comparison`）：比较 `t >= start_i`，输出布尔 `ge`。
  - `Select`（`Programming → Comparison`）：`s` 接 `ge`，`t`（真值）接循环计数 `i`，`f`（假值）接左侧移位寄存器；输出接右侧移位寄存器。
- 原理：从 i=0 到 7 依次检查，凡 `t >= START[i]` 就把索引更新为 i，循环结束得到**满足条件的最后一个 i**，即 t 所在时间片。t=46 → i=1，t=79 → i=3，t=174 → i=7，全部正确且不依赖任何插值行为。

**Step 4 — 取本时间片的 4 个灯色值**：

- `Index Array`：输入 2D 数组 `COLOR` 和 `i`，只接**行索引**端子 → 输出一维数组 `[s0,s1,s2,s3]`。
- `Decimate 1D Array`（`Programming → Array`）：把输出端子向下拉成 **4 个**，直接得到 `s0,s1,s2,s3` 四个标量。
  （若找不到该函数，改用 4 个 `Index Array`，分别接列索引 0/1/2/3，效果相同。）

**Step 5 — 生成 12 个布尔**：对每个 `s` 放 3 个 `Equal?`（`Programming → Comparison`），另一端分别接 I32 常量 `0`、`1`、`2`：

| 色值 s | 红灯布尔 | 绿灯布尔 | 黄灯布尔 |
|---:|---|---|---|
| 0（红） | `s == 0` → TRUE | `s == 1` → FALSE | `s == 2` → FALSE |
| 1（绿） | FALSE | TRUE | FALSE |
| 2（黄） | FALSE | FALSE | TRUE |

即：

```
NS_TH_R = (s0 == 0)   NS_TH_G = (s0 == 1)   NS_TH_Y = (s0 == 2)
NS_LT_R = (s1 == 0)   NS_LT_G = (s1 == 1)   NS_LT_Y = (s1 == 2)
EW_TH_R = (s2 == 0)   EW_TH_G = (s2 == 1)   EW_TH_Y = (s2 == 2)
EW_LT_R = (s3 == 0)   EW_LT_G = (s3 == 1)   EW_LT_Y = (s3 == 2)
```

每个 `Equal?` 输出连到对应名称的 LED 端子。**这一步最容易连错，建议连完立刻把 `step_ms` 设成 50 快跑一遍，看是否每组恰好亮一个灯。**

**Step 6 — 文字与剩余时间显示**：

- `Index Array(NAME, i)` → `slice_name`
- `Index Array(END, i)` 输出减 `t`（`Programming → Numeric → Subtract`）→ `remain_s`
- `t` 直接连 `t_s`

**Step 7 — 周期号（可选但推荐）**：再加一个移位寄存器 `frames`，初值 `0`，每帧 `+1`；`cycle_no = frames / CYCLE + 1`（I32 除法自动取整）。复位时 `frames` 归零。

**Step 8 — 节拍**：`Programming → Timing → Wait (ms)`，输入接 `step_ms`。**必须加**，否则 While 全速空转占满 CPU，且「1 秒」不成立。

**Step 9 — t 推进**：`t + 1` 送 `Quotient & Remainder`（`Programming → Numeric`）与 `CYCLE=175` 取余，余数接右侧移位寄存器。等价于：

```
t_next = (t + 1) mod 175      // t=174 → 0，周期无缝衔接
```

**Step 10 — 复位（可选）**：在 Step 9 前插一个 `Case Structure`，条件接 `reset`；真分支输出 `0`、假分支输出 Step 9 的 `t_next`；同时真分支把 `frames` 也归零。

**Step 11 — 整理**：`Ctrl+B` 不太够用时手动拖线；给 4 个灯组各加一个 `Free Label` 标注；保存为 `十字路口仿真.vi`（保持 LV2014 格式）。

## 4. 备选方案：Formula Node（节点最少，复制即用）

如果不想画 Step 3 的 For 循环，可用 `Programming → Structures → Formula Node` 替代。在框内**右键 → Add Input** 建 `t`（I32），**Add Output** 建 `s0,s1,s2,s3,idx`（均 I32），然后粘贴以下代码：

```c
int32 i;
if (t < 46) i = 0;
else if (t < 50) i = 1;
else if (t < 76) i = 2;
else if (t < 80) i = 3;
else if (t < 140) i = 4;
else if (t < 145) i = 5;
else if (t < 170) i = 6;
else i = 7;

s0 = 0; s1 = 0; s2 = 0; s3 = 0;
if (i == 0) s0 = 1;
else if (i == 1) s0 = 2;
else if (i == 2) s1 = 1;
else if (i == 3) s1 = 2;
else if (i == 4) s2 = 1;
else if (i == 5) s2 = 2;
else if (i == 6) s3 = 1;
else s3 = 2;
idx = i;
```

之后照 Step 5～Step 10 继续（`idx` 就是 `i`，用于查 `NAME` 和 `END`）。

> 课程设计报告若需要体现「图形化数据流 / 状态机」的设计过程，建议用第 3 节的纯 G 查表方案；Formula Node 适合先快速跑通、验证配时数据无误。

## 5. 运行与验收

### 5.1 运行步骤

1. 打开 `十字路口仿真.vi`，确认 `step_ms = 1000`，点运行箭头。
2. 以 1 s 步长连续跑 **至少 3 个完整周期**（525 s）。
3. 嫌慢可把 `step_ms` 改成 `20`（约 10.5 s 跑完 3 周期）做快速预检；**正式验收记录必须用 1000 ms**。
4. 逐秒比对 `逐秒核对表.csv`：该文件 t=0…174 共 175 行，含中文灯色与 0/1/2 数值两栏。

### 5.2 关键切换点核对表（必查 9 个时刻）

| t (s) | 期望事件 | NS_TH | NS_LT | EW_TH | EW_LT |
|---:|---|---|---|---|---|
| 0 | 周期起点，南北直行绿灯亮 | 绿 | 红 | 红 | 红 |
| 46 | 南北直行转黄 | 黄 | 红 | 红 | 红 |
| 50 | 南北左转绿灯亮 | 红 | 绿 | 红 | 红 |
| 76 | 南北左转转黄 | 红 | 黄 | 红 | 红 |
| 80 | 东西直行绿灯亮 | 红 | 红 | 绿 | 红 |
| 140 | 东西直行转黄 | 红 | 红 | 黄 | 红 |
| 145 | 东西左转绿灯亮 | 红 | 红 | 红 | 绿 |
| 170 | 东西左转转黄 | 红 | 红 | 红 | 黄 |
| 175 → 0 | 回到南北直行绿灯，无缝循环 | 绿 | 红 | 红 | 红 |

### 5.3 验收判据

- [ ] 任一秒**恰好一个**机动车灯组非红，且为绿或黄，其余三组恒红
- [ ] 每组三个 LED 任意时刻**恰好一个**亮（红/黄/绿互斥）
- [ ] 黄灯期间该组红灯不亮
- [ ] 9 个切换时刻与 5.2 表完全一致，无提前/滞后一秒（时间片左闭右开）
- [ ] 第 3 周期起点与第 1 周期起点状态一致，无累积漂移
- [ ] 全红时间片数量为 0（本次基准方案不含全红）
- [ ] `t` 显示范围 0…174，从不出现 175

## 6. 报告可直接引用的文字

> 本课程设计以主干路与次干路交叉口为对象，仅对信号灯指示逻辑进行仿真，不输入车流，不评价延误与排队。仿真采用固定配时基准方案，来源于 某日 实地调查，不代表交管部门实时配时。
>
> 周期 T = 175 s，以南北直行绿灯刚亮为 t = 0。全场设 4 个机动车主灯组：南北直行 `NS_TH`、南北左转 `NS_LT`、东西直行 `EW_TH`、东西左转 `EW_LT`。每个相位拆为绿灯与黄灯两个时间片，共 8 个时间片：0—46 s 南北直行绿、46—50 s 黄；50—76 s 南北左转绿、76—80 s 黄；80—140 s 东西直行绿、140—145 s 黄；145—170 s 东西左转绿、170—175 s 黄；175 s 后回到起点循环。任一相位放行时其余三个灯组为红灯。
>
> 南北黄灯 4 s、东西黄灯 5 s 为设定值，处于国标 3—5 s 框架内；全红按 0 s 处理。全周期绿灯 157 s、黄灯 18 s，绿灯时间占比 89.71%（未扣除启动损失与清空损失，不等于有效绿信比）。四个相位的纯绿灯分别为 46 s / 26 s / 60 s / 25 s，占周期 26.29% / 14.86% / 34.29% / 14.29%。
>
> 仿真在 LabVIEW 2014 中实现为「While 循环 + 移位寄存器 + 8 时间片常量表查表」的周期状态机，1 s 步长，逐秒输出四灯组红/黄/绿状态，并以 175 行逐秒核对表连续运行 3 个周期进行校验。右转不受灯控、无非机动车与行人灯组、无全红、无公交优先与感应控制，均为本次建模的显式边界，不代表实际路口的全部控制逻辑。

## 7. 常见坑与排查

| 现象 | 原因 | 处理 |
|---|---|---|
| 灯全灭或乱闪 | 移位寄存器 `t` 没初始化 | 循环左侧必须接 I32 常量 `0` |
| CPU 占满、时间飞快 | 漏了 `Wait (ms)` | 补上，输入接 `step_ms` |
| t=46 时还是绿灯 | 时间片写成了 `<=` 左闭右闭 | 一律 `[start, end)`；For 循环用 `t >= START[i]` |
| 某个灯组两色同时亮 | `Equal?` 的常量写错（如用了 1/2/4 编码） | 色值严格 0=红、1=绿、2=黄 |
| 第 8 片被拆成两片 | `START` 里多加了 175 | 只保留 0…170 共 8 个起点 |
| 出现 `t=175` | 取余写成了 `t mod 175` 而非 `(t+1) mod 175` | 按 Step 9 修正 |
| 停止按钮要按两次 | 机械动作设置问题 | 右键 → `Mechanical Action` → 选 `Latch When Released` |
| LED 亮起来都是绿色 | 没改 On/Off 颜色 | 按 2.3 节逐灯设置 |
| 用 2026 打开后 2014 打不开 | VI 版本被升级 | **始终用 LV2014 打开和保存**；改前先复制一份备份 |

## 9. 以后要改配时怎么办

**只改一处**：编辑 `gen_timing_table.py` 里的 `PHASES`（相位名、放行灯组、纯绿灯秒、黄灯秒），在 `labview/V1-demo/` 目录运行：

```
python gen_timing_table.py
```

脚本会重新生成 `时间片常量表.csv` 与 `逐秒核对表.csv`，并断言校验周期、绿/黄合计、边界连续性、每相位绿灯秒数、每秒灯态合法性。校验通过后，按新表更新 VI 里的 `START`/`END`/`COLOR`/`NAME` 四个数组常量即可 —— 程序框图结构无需改动。

若将来确认存在全红 R 秒，需在 `PHASES` 中为每个相位增加一个全红时间片，并把灯态全设为 `0`；此时周期变为 `175 + 4R`，`逐秒核对表.csv` 行数随之变化。
